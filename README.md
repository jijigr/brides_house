# КовиКружево — свадебный салон

Каталог свадебных платьев с фильтрами и корзиной. В корне репозитория лежит готовая главная страница `index.html`, поэтому GitHub Pages сможет открыть сайт вместо показа HTML-кода.

## Публикация на GitHub Pages

Загрузите содержимое этой папки в корень репозитория. На GitHub откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**. После публикации GitHub покажет адрес сайта в этом же разделе.

## Полная версия с записью и кабинетом

GitHub Pages размещает только статические файлы: каталог откроется, но онлайн-запись и кабинет администратора требуют Node.js-сервера. Для полного функционала нужен хостинг, который запускает `server.mjs`.

Локально нужен Node.js 20 или новее. Скопируйте `.env.example` в `.env`, задайте собственный `ADMIN_PASSWORD`, затем запустите `node server.mjs`. Сервер откроет сайт на <http://127.0.0.1:4173/>.

Файлы с паролями и данными клиентских записей не входят в эту папку.
